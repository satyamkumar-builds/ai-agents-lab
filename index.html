02 · How it works

Bring your own key — it never leaves your browser

1

Get a free key

A Google Gemini API key from aistudio.google.com/apikey takes about a minute. OpenRouter and Groq keys work too.

2

Paste it into a tool

The key is saved in your browser's local storage — on your device only. There is no account and no server to send it to.

3

Work, copy, download

Requests go straight from your browser to the AI provider. Outputs can be copied or downloaded, and your recent work stays in your browser for next time.

FlowStudio works the same way with your Meta WhatsApp credentials instead of an AI key. WhatsApp Message Studio's templates and the Prompt Library need nothing at all.

03 · Inside the tools

What each one actually gives you

StudyBuddy AI

Built for students who are told to "just read the chapter". Every explanation follows the same teaching order: story, example, key points, check question.

Example output

Topic: Photosynthesis Story: Ek paudha ek chhoti si factory hai... Example: Jaise tum khana banate ho, waise paudha sunlight se apna khana banata hai. Key points: sunlight + water + CO2 → glucose + oxygen. Check: Agar paudhe ko 2 din andhere me rakho, to kya hoga?

CodeMentor AI

A mentor, not an answer machine. It explains before it fixes, names the concept behind every bug, and ends with a practice task on the same idea.

Example output

Bug: line 3 — loop i <= marks.length tak chalta hai. Reason: array ka last index length-1 hota hai, isliye last round me undefined print hota hai. Fix: i < marks.length Practice: ab ek loop likho jo array ko ulta print kare.

Salon & Business Assistant

See how a support agent for your own shop would behave before you pay anyone to build one. It answers only from the details you give it — and says so when it does not know.

Example output

Customer: Haircut ka price kya hai? Agent: Haircut ₹199 hai. Beard ke saath combo ₹249 me padega. Kal ke liye booking karun?

ScriptWriter AI

Structured scripts, not paragraphs of advice: title, a hook written for the first three seconds, body lines timed to your duration, on-screen text and a CTA.

Example output

TITLE: Line me khade hona band karo HOOK (0–3s): Salon jao aur seedha chair par baitho, bina line ke. BODY: ... ON-SCREEN TEXT: No lines. No waiting. CTA: Comment me LINK likho, tool ka link bhej dunga.

WhatsApp Message Studio

45 ready templates across five purposes and three languages. Fill in your business name and the offer; get three variants you can copy or open directly in WhatsApp.

Example output

Namaste Rahul ji! Glow & Shine Salon se ek khaas khabar hai. Haircut + Beard combo sirf ₹249, is Sunday tak. Apna time book karne ke liye isi number par reply karein.

FlowStudio

Automation you can see. Blocks make the flow readable — trigger, template message, delay, follow-up — and a live log shows every send and every error, honestly.

Example log

[10:02:11] ▶ RUN shuru (Manual run) — 1 recipient, 4 blocks. [10:02:12] Step 2: ✓ template "hello_world" bheja gaya +91… [10:02:18] Step 4: ✓ text message bheja gaya +91… [10:02:18] ■ RUN khatm — sent: 2, failed: 0.

Social Post Generator

Platform rules are built in: hashtags counted for Instagram, a tighter format for LinkedIn, under 280 characters for X — plus a posting-time tip for each.

Example output

Salon aaye, line me khade rahe, aadha din gaya. Ab token phone par, time par seedha chair. #SalonLife #SmallBusiness #India

Email Replier

Drafts that answer every point in the email and stop there — no invented dates, prices or promises. Five tones, from friendly to firm.

Hello Rakesh ji, Thank you for writing. A simple shop website with a product catalogue and WhatsApp ordering is possible. I will share the exact quotation and timeline by tomorrow evening. — Satyam Kumar

Profile Optimizer

Three headline options, two bio versions and a short list of what changed and why. A student sounds like a strong student — never a fake CEO.

Prompt Library

The prompts students actually reuse — Feynman explanations, mock viva, bug hunts, interview practice — written with placeholders so one prompt fits any subject.

Example prompt

Explain [topic] to me like a teacher: first a tiny real-life story, then a simple example, then the key points in bullets. End with one question to test me. If I answer wrong, correct me gently and explain again.

04 · Questions

Before you ask

Is it really free?

Yes. The Lab is open source under the MIT licence and there is nothing to buy here. The AI tools use your own API key — Gemini's free tier is enough for normal use. WhatsApp Message Studio's templates and the Prompt Library cost nothing at all.

Where does my API key go?

Into your browser's local storage, and from your browser directly to the provider you chose (Google, OpenRouter or Groq). There is no Lab server, so your key is never sent to us. You can check this in the source — every page is plain HTML and JavaScript.

Why bring my own key instead of just using a chatbot?

A general chatbot gives you a conversation; these tools are shaped around one job each — a fixed script format, platform-specific post rules, templates that follow WhatsApp's compliance rules. Same model underneath, but the output is finished work you can copy, download and reuse.

Can I use the code in my own project?

Yes — that is what the MIT licence is for. Copy it, change it, ship it; keep the licence notice. If you improve something, a pull request on GitHub is welcome.

What are the honest limits?

These are small, single-purpose tools, not a platform. FlowStudio runs only while its page is open — there is no background server. AI answers depend on the model behind your key. Everything here favours being clear about that over pretending otherwise.
