# Changelog

## v2.0 — 2026-11-17

A full redesign and repositioning of the Lab.

- **New design — white premium.** The dark blue theme is gone. Every page now uses an off-white background, near-black text, hairline borders and generous whitespace, with Fraunces serif headings and Inter body text. One restrained accent (deep red), no gradients, no glow.
- **New positioning.** The homepage now leads with outcomes instead of a tool count: what each tool finishes, why bring-your-own-key matters, and honest badges on every card ("Bring your own key", "No key needed", "Your own credentials").
- **New homepage sections.** GitHub buttons in the hero, a "How BYOK works" three-step section, a per-tool detail section with a concrete example output for every tool, and an FAQ (cost, where your key goes, why BYOK, licence, honest limits).
- **New tool: Prompt Library.** 23 copy-ready prompts for study, exam prep, coding help, placement interviews and writing — filterable, searchable, one-click copy. No key needed.
- **Tool depth on every page.** Chat tools now keep your conversation in your browser between visits and add Copy / Download buttons to every AI reply. Form tools gained realistic prefilled examples, Download (.txt) on every output, and a "Recent outputs" history (last 5, stored only in your browser). WhatsApp Message Studio can download all variants at once. FlowStudio can export and import flows as JSON.
- **Open-source furniture.** README rewritten with a full tool table, quick start and tech notes. MIT LICENSE added.
- **No runtime CSS CDN.** The Tailwind Play CDN script was replaced with a small precompiled stylesheet (`lab.css`, ~7 KB) linked by every page — the site now renders identically offline and loads faster.

## v1.0 — 2026-11-15

Initial release: 9 tools (StudyBuddy, CodeMentor, Business Assistant, ScriptWriter, WhatsApp Message Studio, Social Post Generator, Email Replier, Profile Optimizer, FlowStudio) with bring-your-own-key AI calls made directly from the browser.
