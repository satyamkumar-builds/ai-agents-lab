Tool 09 · Automation · Bring your own credentials

FlowStudio

WhatsApp automation ka visual builder — n8n style. Blocks jodo (trigger → message → delay), apni khud ki Meta WhatsApp Cloud API details daalo, aur flow yahin browser se chalao. BYOC — Bring Your Own Credentials.

1 · CONNECT — META WHATSAPP CLOUD API

Credentials sirf tumhare browser (localStorage) me rehte hain — sirf Meta ki API ko bheje jate hain, kisi aur ko nahi. Details Meta for Developers → WhatsApp → API Setup me milte hain.

⚠️ Pehle ye samajh lo: Message sirf unhi numbers par bhejo jinhone tumse WhatsApp par baat karne ki permission (opt-in) di hai. Bina permission ke bulk/spam messages bhejne par WhatsApp tumhara number ban kar sakta hai — ye Meta ka rule hai. Isi liye: ek run me max 20 recipients, har send ke beech automatic gap, aur naya message hamesha template se shuru hota hai (yahi compliant tareeka hai). Ye tool koi number scrape ya import nahi karta — number tum khud type karte ho.
Honest limit: Browser edition — flows run while this page is open; there is no server or background scheduler. Page band = flow band. Free-text messages sirf tab deliver hote hain jab customer ne pichhle 24 ghante me tumhe message kiya ho (WhatsApp ka 24-hour window rule) — naye customers ke liye hamesha template message use karo.

Recipe load karne se neeche ka flow badal jayega. Template names apne Meta account ke approved templates se badal lena — hello_world Meta ka free test template hai jo har account par chalta hai.
